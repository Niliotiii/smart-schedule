# Implementation Plan: Gerar Nova Senha para Usuário

**Branch**: `021-user-reset-password` | **Date**: 2026-05-20 | **Spec**: [spec.md](./spec.md)
**Input**: Feature specification from `/specs/021-user-reset-password/spec.md`

## Summary

Adicionar um botão "Resetar Senha" na coluna de ações da listagem de usuários que, ao ser clicado, gera uma senha aleatória de 24 caracteres, persiste no banco e exibe em um modal que só pode ser visto uma vez. Inclui uma nova permissão `users:reset_password` para controlar acesso.

## Technical Context

**Language/Version**: Node 24 / TypeScript 6.0 / Vue 3.5  
**Primary Dependencies**: AdonisJS 7, Inertia.js 2, PrimeVue 4, Lucid ORM 22  
**Storage**: PostgreSQL 16  
**Testing**: Japa + Playwright  
**Target Platform**: Web (desktop/mobile browsers)  
**Project Type**: Full-stack web application (AdonisJS monolith with Inertia + Vue SPA)  
**Performance Goals**: N/A (admin action, not hot path)  
**Constraints**: Senha exibida apenas uma vez no modal — ao fechar, não pode ser recuperada  
**Scale/Scope**: Administradores gerenciando usuários do sistema

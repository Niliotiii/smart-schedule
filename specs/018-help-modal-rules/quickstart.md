# Quickstart: Help Modal with Rules

**Date**: 2026-05-18

## Integration Scenarios

### 1. User opens help modal

1. User is on any page with the sidebar
2. Sees a "?" or info button above "Sair" in the sidebar
3. Clicks it → Dialog opens with two tabs
4. "Regras de Alocação" tab active by default with allocation rules
5. User clicks "Status de Escala" → sees status descriptions and transitions
6. User clicks X, outside, or Escape → modal closes

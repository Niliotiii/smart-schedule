# Quickstart: Login Branding Refactor

**Date**: 2026-05-18

## Integration Scenarios

### 1. User visits login page

1. User navigates to `/login`
2. Sees a branded login page with decorative background, icon, and "Smart Schedule" title
3. Fills in email and password
4. Clicks "Entrar" → redirects to dashboard on success
5. On invalid credentials → sees error message as before

### 2. Dark mode toggle

1. User is on the login page
2. Clicks the dark/light toggle button (top-right, from GuestLayout)
3. The branded page adapts to dark/light mode correctly

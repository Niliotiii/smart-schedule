## Summary

Refactor the login page to convey brand identity for Smart Schedule — a church schedule management system. The login page currently uses a minimal centered card with title, email/password fields, and submit button. It will be enhanced with a decorative gradient background, a brand icon area, an accent bar, and enhanced typography — all using existing PrimeVue Aura theme tokens and Tailwind CSS. No new dependencies, no backend changes.

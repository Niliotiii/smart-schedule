# Quickstart: Dashboard Schedule Calendar

**Date**: 2026-05-18

## Integration Scenarios

### 1. User views dashboard with schedule calendar

1. User logs in and lands on dashboard
2. Sees a tabbed area: "Calendário de Escalas" and "Liturgia Diária"
3. "Calendário de Escalas" tab is active by default
4. Calendar grid shows current month with green dots on assigned days
5. User clicks a green day → detail panel shows schedule info (name, time, community, priest, users, roles)
6. User clicks a gray day → detail panel shows "Nenhuma escala neste dia"

### 2. Monthly navigation

1. User clicks next/previous month arrows on the calendar
2. Calendar updates to show the new month's days with correct green/gray indicators
3. Detail panel updates or clears

### 3. Liturgia tab

1. User clicks "Liturgia Diária" tab
2. Existing liturgia content renders with date picker, readings, orações, accordions
3. All functionality works exactly as before

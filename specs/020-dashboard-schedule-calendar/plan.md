# Implementation Plan: Dashboard Schedule Calendar

**Branch**: `020-dashboard-schedule-calendar` | **Date**: 2026-05-18 | **Spec**: [spec.md](spec.md)
**Input**: Feature specification from `specs/020-dashboard-schedule-calendar/spec.md`

## Summary

Replace the standalone liturgia section on the dashboard with a tabbed layout. The first tab shows a monthly calendar where days the user has schedule assignments appear green and other days gray. Clicking any day opens a detail panel with schedule info (name, time, community, priest, assigned users, roles). The second tab contains the existing liturgia content preserved as-is.

## Technical Context

**Language/Version**: TypeScript, Vue 3 (Composition API), AdonisJS 6  
**Primary Dependencies**: PrimeVue 4.5.5 (Aura theme), Lucid ORM, Inertia.js, Luxon  
**Storage**: PostgreSQL via Lucid ORM (query existing ScheduleAssignment data)  
**Testing**: N/A — verified by build  
**Target Platform**: Web (responsive)  
**Project Type**: Web application (monolith with Inertia.js frontend)  
**Performance Goals**: Calendar renders within 2 seconds with all assignments loaded  
**Constraints**: Must preserve existing liturgia functionality exactly in the second tab  
**Scale/Scope**: Dashboard controller backend query + new ScheduleCalendar component
